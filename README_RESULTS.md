# Master Thesis Experimental Results

## Thesis Topic

**Comparative Evaluation of Multi-Agent and Single-Agent LLM Systems for Business Decision Support**

This repository contains the experimental implementation and evaluation pipeline used to compare four LLM-agent architectures on the FinQA financial numerical reasoning benchmark.
